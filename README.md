---

## 📚 About Streamlit

**Streamlit** is an open-source Python framework that allows developers and data scientists to build beautiful, interactive web applications with just a few lines of code.

It is widely used for:

* Data Science Projects
* Machine Learning Model Deployment
* Data Dashboards
* Interactive Data Visualization
* AI Applications
* Python Web Apps

# ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/streamlit-learning.git
```

### 2. Move into the project folder

```bash
cd streamlit-learning
```

### 3. Install dependencies

```bash
pip install streamlit pandas requests
```

### 4. Run any Streamlit app

```bash
streamlit run filename.py
```

Example:

```bash
streamlit run hello_chai_app.py
```
